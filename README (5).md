# Food Delivery System

## Project Description
A command-line food delivery application built using Object-Oriented Programming (OOP) principles in Python. The system models core entities such as customers, delivery partners, restaurants, menu items, and orders. It handles comprehensive workflows including user registrations, wallet top-ups with validation rules, menu management, dynamic bill calculations (subtotal, 5% GST, and packaging fees), order status transitions, OTP-verified deliveries, and notification systems.

## Requirements
- Python 3.8+
- Google Colab or Jupyter Notebook environment

## How to Run
1. Execute the class definition cells or run `food_delivery.py` to load all system classes.
2. Run `demo.py` to simulate the full end-to-end workflow execution.
